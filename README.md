# cat_vasya_game
Описание работ

## Модуль 1
При выполнении первого модуля был создан абстрактный класс `Unit`. Внутри класса был создан метод `__init__`, в котором заданы основные характеристики юнита: strength (сила), dexterity (ловкость), constitution (телосложение), wisdom (мудрость), intelligence (интеллект) и charisma (харизма). Также в классе были объявлены абстрактные методы для вычисления максимального здоровья, урона и защиты. Затем были созданы классы `Character` и `Monster`, которые наследуются от класса `Unit`. В этих классах реализованы методы вычисления максимального здоровья, урона и защиты по формулам, указанным в задании. Для класса `Character` реализованы формулы расчёта характеристик персонажа, а для класса `Monster` — отдельные формулы расчёта характеристик монстра. Все вычисления выполняются с округлением результата до целого числа вниз.

## Модуль 2
Во втором модуле архитектура программы была переработана. Класс `Monster` был удалён, так как по условию задания теперь от абстрактного класса `Unit` наследуется только класс `Character`. В класс `Character` был добавлен атрибут `character_class`, который определяет игровой класс персонажа. Поддерживаются следующие классы: `warrior`, `mage` и `hunter`. Внутри класса `Character` были реализованы различные формулы вычисления урона и защиты в зависимости от выбранного игрового класса. Для вычисления характеристик используются условные конструкции `if` и `elif`. Формула вычисления максимального здоровья осталась общей для всех персонажей. Также в конструкторе класса `Character` была реализована автоматическая инициализация максимального здоровья, урона и защиты персонажа. Дополнительно была добавлена проверка корректности введённого игрового класса. Если пользователь передаёт недопустимое значение `character_class`, генерируется исключение `ValueError`.
